# Queuebone

Queuebone a high performance job queue for Node.js, written in Typescript. It's based on [MinionJS](https://github.com/mojolicious/minion.js).

The following backends are currently available for Queuebone:

- PostgreSQL backend
- REST backend (worker only)
- Memory backend (only for testing)
